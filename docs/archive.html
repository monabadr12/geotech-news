Settings

These are stored only in this browser, on this device. They are never saved to the website or the repository, so other visitors cannot use them.

How to create the token (2 minutes)
  1. Open github.com → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Name it news scan button, choose an expiry date, and under Repository access pick Only select repositories → geotech-news.
  3. Under Permissions → Repository permissions set Actions to Read and write. Nothing else is needed.
  4. Press Generate token, copy it and paste it above.
About the key

Create a key at console.anthropic.com → API Keys. A separate key for the website, with a monthly spend limit, is a sensible safeguard. The key is sent only to Anthropic, directly from this browser.
