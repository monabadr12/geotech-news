E-mail to the editorial team

The summary goes out every Monday after the morning scan, and an alert follows any scan that finds a new story rated 5 / 5. Send summary now e-mails the summary of the last full week (week 42, 12–18 Oct 2026), through its workflow on GitHub.

How e-mail is set up
  1. With the AI assistant's Google connector (no mail server needed): paste the current assistant/bridge.gs into its Apps Script project, add the Script property NOTIFY_TOKEN (a long random text) and, if you like, MAIL_TO (addresses separated by commas; empty sends to your own address). Run testEmail once to allow e-mail, deploy a new version, and add the same text as the GitHub secret NOTIFY_TOKEN.
  2. Or with a mail server: the GitHub secrets SMTP_HOST, SMTP_PORT (587), SMTP_USER, SMTP_PASSWORD and MAIL_TO.
  3. Check it with the Events calendar and weekly summary workflow on GitHub: choose send a test e-mail. Settings (which e-mails, the day) are under alerts: in config.yaml.
