Method & sources

How the digest is made

A scheduled scan reads specialist, institutional and trade sources plus worldwide news searches, filters them for geotechnical substance, and files the result under the magazine's eight themes.

Each run

  1. Collect. 26 websites and 76 Google News searches (8 core searches in 7 English editions, plus 20 further searches including 14 in other languages). The scan runs every day at 05:00 Cairo time, and on demand with the Scan now button. Each run looks back 60 hours; stories already shown are remembered for 45 days and never repeated.
  2. Score and categorise. Headlines and summaries are scored against 56 English keywords and 454 terms in 11 other languages. Each foreign term counts as its English equivalent (for example glissement de terrain, deslizamiento, longsor and انهيار أرضي all count as “landslide”), so every story is filed under an English theme. Specialist sources earn bonus points, noise terms lose points, near-identical headlines are merged. A story needs 3 points to go forward.
  3. Triage. Up to 130 candidates go to Claude, which rates each 1–5 for geotechnical substance (below 3 is dropped), confirms the theme, suggests a use, writes a one-sentence magazine angle, and translates non-English headlines.
  4. Publish & archive. Up to 60 stories per digest. Every digest is stored permanently, grouped into three-month issue windows, and exported to Excel.

Known limits

Coverage of a country depends on what its press publishes online in a language covered here. Google News favours recency and mainstream outlets, so a major landslide is picked up readily while a quiet technical advance may not be — which is why society and institutional feeds are read directly.

Headlines link to the original publishers. Treat every story as a lead and verify with the primary source before publishing. Ratings, themes and angles are machine-assisted suggestions for the editorial team. Website report (Word)

Settings

These are stored only in this browser, on this device. They are never saved to the website or the repository, so other visitors cannot use them.

How to create the token (2 minutes)
  1. Open github.com → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Name it news scan button, choose an expiry date, and under Repository access pick Only select repositories → geotech-news.
  3. Under Permissions → Repository permissions set Actions to Read and write. Nothing else is needed.
  4. Press Generate token, copy it and paste it above.
About the key

Create a key at console.anthropic.com → API Keys. A separate key for the website, with a monthly spend limit, is a sensible safeguard. The key is sent only to Anthropic, directly from this browser.
